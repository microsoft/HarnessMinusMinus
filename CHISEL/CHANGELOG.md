# Changelog

## 0.2.0

- Refresh GAIA2 feedback handling, ALFWorld modular control, and QA typed recovery.
- Add schema-bound CoT action banks, typed public receipt bindings, exact native execution receipts, and lossless public context compression.
- Add a native Responses/MCP bank boundary with bundled JavaScript contracts. The caller supplies metered model calls and native execution; Node.js is optional for other controllers.
- Add supported candidate selection, conditional microplans, observed feedback plans, fragment contracts, residual programs, grounded continuations, and entry guard refinement.
- Extend synthetic regression coverage, package source mappings, and publication checks for source trees and built distributions.

Existing public imports and protocol identifiers are retained. Scientific results, learned banks, deployment configuration, and private operational records remain outside this package.

## 0.1.0

Initial standalone controller extraction with provider-independent QA, ALFWorld, spreadsheet, terminal, and GAIA2 interfaces.
